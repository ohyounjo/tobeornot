개인정보처리방침

최종 업데이트: 2026년 10월 9일

1. 목적

Google Workspace CLI 학습용 개인 앱(이하 “앱”)은 Google Workspace API와 Google Workspace CLI를 개인적으로 학습하고 확인하기 위한 용도로만 사용됩니다.

2. 접근하는 데이터

앱은 사용자가 Google OAuth 동의 화면에서 명시적으로 승인한 범위의 Google 계정 데이터에만 접근합니다. 승인하지 않은 데이터에는 접근하지 않습니다.

3. 저장 및 처리

  • OAuth 인증 정보와 Google API에서 조회한 데이터는 앱을 실행하는 개인 로컬 환경에서만 처리·저장됩니다.
  • 앱 운영자가 관리하는 별도의 서버나 중앙 데이터베이스로 Google 계정 데이터를 전송하지 않습니다.
  • Google 계정 데이터는 광고, 프로파일링 또는 서비스 외 목적에 사용하지 않습니다.

4. 제3자 제공

Google 계정 데이터를 제3자에게 판매·대여·제공하지 않습니다. 다만 Google API 호출 자체는 Google의 서비스 약관과 API 정책에 따라 처리됩니다.

5. 보관 및 삭제

로컬 환경에 저장된 데이터는 사용자가 해당 로컬 환경에서 직접 삭제할 수 있습니다. Google 계정의 앱 접근 권한은 Google 계정의 서드 파티 연결 관리에서 언제든지 철회할 수 있습니다.

6. Google API 서비스 사용자 데이터 정책

이 앱은 Google API 서비스 사용자 데이터 정책을 준수하는 것을 원칙으로 합니다. 앱의 데이터 접근 범위가 변경되는 경우 이 정책도 함께 업데이트합니다.

7. 문의 및 변경

이 정책의 변경 사항은 이 페이지에 게시합니다. 프로젝트 관련 공개 문의는 GitHub 저장소 Issues를 이용해 주세요.
